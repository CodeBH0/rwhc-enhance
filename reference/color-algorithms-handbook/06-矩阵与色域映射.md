# 06 · 矩阵与色域映射

> 本篇规定 RGB 与 XYZ 之间的矩阵构造、归一化、以及色域外颜色的处理。
> 概念背景（色域的几何含义）见 `00-从零理解色彩数学.md` §7。

---

## 1. 问题定义

给定显示设备的四个色度坐标——三原色 $(x_r,y_r),(x_g,y_g),(x_b,y_b)$ 与白点 $(x_w,y_w)$——
求 $3\times3$ 矩阵 $M$，使得

$$
\begin{bmatrix}X\\Y\\Z\end{bmatrix} = M \begin{bmatrix}R\\G\\B\end{bmatrix}
$$

**为什么不能直接得到 $M$**：色度坐标只给出**方向**，不含亮度。三个原色的亮度是未知的，
必须借助"白点由三原色混合而成"这一约束解出。

---

## 2. 构造流程

### 2.1 第一步：把色度坐标化为单位亮度向量

由 $X = Yx/y$、$Z = Y(1-x-y)/y$，令 $Y = 1$，得每个原色的**方向向量**：

$$
\vec r_0 = \begin{bmatrix}x_r/y_r\\ 1\\ (1-x_r-y_r)/y_r\end{bmatrix},\qquad
\vec g_0 = \begin{bmatrix}x_g/y_g\\ 1\\ (1-x_g-y_g)/y_g\end{bmatrix},\qquad
\vec b_0 = \begin{bmatrix}x_b/y_b\\ 1\\ (1-x_b-y_b)/y_b\end{bmatrix}
$$

同理白点：

$$
\vec w_0 = \begin{bmatrix}x_w/y_w\\ 1\\ (1-x_w-y_w)/y_w\end{bmatrix}
$$

### 2.2 第二步：解出三原色的亮度配比

白点必须等于三原色按某配比 $S = (S_r,S_g,S_b)$ 线性组合：

$$
A S = \vec w_0,\qquad A = [\,\vec r_0\ \ \vec g_0\ \ \vec b_0\,]
$$

故

$$
S = A^{-1}\,\vec w_0
$$

（这一步是**普通 3×3 线性方程组**。$A$ 一般可逆；若不可逆说明三个原色共线，属于非法输入。）

### 2.3 第三步：组装矩阵

$$
M = \begin{bmatrix}
S_r\,x_r/y_r & S_g\,x_g/y_g & S_b\,x_b/y_b\\[1mm]
S_r & S_g & S_b\\[1mm]
S_r\,(1-x_r-y_r)/y_r & S_g\,(1-x_g-y_g)/y_g & S_b\,(1-x_b-y_b)/y_b
\end{bmatrix}
$$

即把 $\vec r_0,\vec g_0,\vec b_0$ 按 $S$ 逐列缩放。

### 2.4 校验

构造完成后**必须**验证：

$$
M \begin{bmatrix}1\\1\\1\end{bmatrix} = \vec w \quad\text{（白点三刺激值）}
$$

并且第二行（$Y$ 行）之和应等于 $Y_w$（通常归一化为 1）。

---

## 3. 两种归一化（务必区分）

矩阵算出来后常需归一化，但有两个**完全不同**的操作：

### 3.1 按 Y 归一（整体缩放）

取**第二行（$Y$ 行）的三个元素之和**作为除数，**整个矩阵的所有 9 个元素**同除以它：

$$
s = M_{20} + M_{21} + M_{22}
$$

$$
M \leftarrow M / s \quad(\text{对所有元素})
$$

**效果**：$R=G=B=1$ 时输出的 $Y$ 恰好为 1。这是"相对亮度"标定的标准做法。

**边界**：若 $s \le 0$，**不做任何修改**并返回（不要除零，也不要报错到中断流程）。

### 3.2 按行归一（逐行独立）

每一行各自除以本行元素之和：

$$
M_{i,:} \leftarrow \frac{M_{i,:}}{\sum_j M_{ij}},\qquad i = 0,1,2
$$

**效果**：每行元素和为 1。
典型用途是只关心**相对配比**的场景——例如 $Y$ 行会变成亮度权重
$(0.2126,\ 0.7152,\ 0.0722)$（Rec.709）。

> **混淆这两种操作是常见错误**。要点：
> - "按 Y 归一"用**一个**标量除全部元素；
> - "按行归一"用**三个**不同的标量分别除三行。

---

## 4. 逆矩阵与色域判定

### 4.1 逆变换

$$
\begin{bmatrix}R\\G\\B\end{bmatrix} = M^{-1}\begin{bmatrix}X\\Y\\Z\end{bmatrix}
$$

### 4.2 色域内/外的判定

若某颜色落在设备色域**之外**，$M^{-1}$ 作用后会出现：

- 某个分量为**负数**，或
- 某个分量 **> 1**

**判据**：$\min(R,G,B) < 0$ 或 $\max(R,G,B) > 1$ 即视为色域外。

### 4.3 色域映射策略

对色域外的颜色，需把它"拉回"可表示范围。几种策略，按保真度排序：

| 策略 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **裁切**（clip）| 各分量直接 clamp 到 $[0,1]$ | 最快 | 会偏色、丢层次 |
| **保亮度裁切** | 只压彩度，保持 $Y$ 不变 | 亮度正确 | 仍可能偏色 |
| **保色相映射** | 沿 $LCh$ 的 $C$ 方向压缩到边界 | 观感最好 | 需转到 Lab/LCh 空间 |
| **感知映射** | 全局压缩（含色域内颜色）| 层次最平滑 | 计算量大 |

**推荐**：显示器校准场景用**保色相压缩**——保持 $h$ 与 $L^*$，只把 $C^*$ 缩到色域边界。

算法概要：

```
1. 把目标色转成 Lab，得 (L*, C*, h)
2. 在 h 方向上二分查找最大的 C* 使其仍在色域内
3. 用该 C* 重建颜色
```

"是否在色域内"的判定用 §4.2。

## 5. 常见色域矩阵参考值

以下为**按 §2 流程构造**后，再用 §3.1 按 Y 归一的结果，可用于比对实现：

### Rec.709 / sRGB → XYZ（D65）

$$
M \approx \begin{bmatrix}
0.4124564 & 0.3575761 & 0.1804375\\
0.2126729 & 0.7151522 & 0.0721750\\
0.0193339 & 0.1191920 & 0.9503041
\end{bmatrix}
$$

$Y$ 行 $(0.2127, 0.7152, 0.0722)$ 即 Rec.709 亮度权重。

### Rec.2020 → XYZ（D65）

$Y$ 行应为 $(0.2627,\ 0.6780,\ 0.0593)$。

### Adobe RGB (1998) → XYZ（D65）

$Y$ 行应为 $(0.2974,\ 0.6274,\ 0.0753)$。

**用第一行或第二行与上表比对，即可确认你的原色数据与白点引用是否正确。**

> ⚠️ **精度敏感提示**：上表的数值精度取决于**输入色度的位数**。
> 若用 2 位小数的白点 $(0.3127, 0.3290)$ 与 2 位小数的原色，算出的 $Y$ 行会是
> 约 `(0.2126390, 0.7151687, 0.0721923)`——与上表在**第 5 位小数**相差约 $3\times10^{-5}$。
> 这个差异**不是错误**，而是白点/原色取值精度不同造成的。
> 做矩阵比对时，前 4 位小数一致即可认为正确；若要求更高一致度，
> 必须与对方使用**完全相同**的白点与原色数值。

**用哪一行做校验最快**：$Y$ 行即配比向量 $S$，它是公式（§2.2）的直接产物，不含额外的列缩放误差。

## 6. 多矩阵组合

若需串联多个变换（例如 源色域 → XYZ → 目标色域），矩阵可以直接相乘：

$$
M_{\text{total}} = M_{\text{target}}^{-1}\,M_{\text{source}}
$$

**注意顺序**：从右往左作用。若写成 $M_{\text{source}}^{-1}M_{\text{target}}$，结果完全错误。

**数值注意**：连续三次以上的矩阵乘法会放大舍入误差，建议：
- 中间结果保持双精度；
- 必要时对最终矩阵做一次正交化或按 §2.4 重新校验白点。

## 7. 实现清单

```python
import numpy as np

def primaries_to_matrix(prim, white):
    """
    prim = ((xr,yr), (xg,yg), (xb,yb)) ; white = (xw, yw)
    返回按 Y 归一化后的 3x3 矩阵（列分别为 R,G,B 的 XYZ 向量）。
    """
    def unit(x, y):
        return np.array([x/y, 1.0, (1.0 - x - y)/y])

    r0 = unit(*prim[0]); g0 = unit(*prim[1]); b0 = unit(*prim[2])
    w0 = unit(*white)

    A = np.column_stack([r0, g0, b0])
    S = np.linalg.solve(A, w0)

    M = A * S            # 逐列缩放
    return normalize_by_Y(M)

def normalize_by_Y(M):
    """用第二行(Y 行)元素之和归一化整个矩阵；和 <= 0 时原样返回。"""
    s = M[1, 0] + M[1, 1] + M[1, 2]
    if s > 0.0:
        M = M / s
    return M

def normalize_by_row(M):
    """每行各自归一化（行和为 1）。"""
    out = M.copy()
    for i in range(3):
        s = out[i].sum()
        if s > 0.0:
            out[i] /= s
    return out

def convert(rgb, M):
    rgb = np.asarray(rgb, dtype=float)
    return M @ rgb

def in_gamut(rgb, tol=1e-9):
    return (min(rgb) >= -tol) and (max(rgb) <= 1.0 + tol)

def gamut_map_preserve_hue(XYZ, M, lab_roundtrip):
    """
    把色域外的 XYZ 沿 Lab 的 C* 方向压回边界。
    lab_roundtrip 需提供 xyz->lab 与 lab->xyz（见 01 篇）。
    这里给出的是框架，具体二分区间需按应用设定。
    """
    rgb = np.linalg.solve(M, XYZ)
    if in_gamut(rgb):
        return XYZ, rgb
    L, C, h = lab_roundtrip.xyz_to_lch(XYZ)
    lo, hi = 0.0, C
    for _ in range(40):
        mid = 0.5*(lo + hi)
        cand = lab_roundtrip.lch_to_xyz(L, mid, h)
        if in_gamut(np.linalg.solve(M, cand)):
            lo = mid
        else:
            hi = mid
    best = lab_roundtrip.lch_to_xyz(L, lo, h)
    return best, np.clip(np.linalg.solve(M, best), 0.0, 1.0)
```

## 8. 自检用例

用 `prim` = **Rec.709 / sRGB** 三原色（$R(0.64,0.33),\ G(0.30,0.60),\ B(0.15,0.06)$）、
`white` = D65 $(0.3127, 0.3290)$：

| 检查 | 期望 |
|---|---|
| 矩阵 $Y$ 行 | `[0.2126729, 0.7151522, 0.0721750]`（误差 < 1e-6）|
| $M\cdot(1,1,1)^T$ | $X \approx 0.950456,\ Y = 1.0,\ Z \approx 1.088754$ |
| $M\cdot(1,0,0)^T$ 归一化后的 $xy$ | $(0.64, 0.33)$（即 R 原色）|
| $M\cdot(0,1,0)^T$ 归一化后的 $xy$ | $(0.30, 0.60)$（即 G 原色）|
| $M\cdot(0,0,1)^T$ 归一化后的 $xy$ | $(0.15, 0.06)$（即 B 原色）|

换成 Adobe RGB 原色（$G$ 改为 $(0.21, 0.71)$）再测一遍，$Y$ 行应变为
`[0.2973614, 0.6273558, 0.0752828]`。
**这两组数值是区分 Rec.709 与 Adobe RGB 最快的判据**（它们的红、蓝原色相同，只有绿色不同）。

| 检查 | 期望 |
|---|---|
| `normalize_by_Y` 后的第二行和 | `1.0` |
| `normalize_by_row` 后每行和 | `[1.0, 1.0, 1.0]` |
| `in_gamut([1.1, 0.5, 0.5])` | `False` |

第 3–5 行是**最强校验**：它直接验证"矩阵的每一列确实对应一个原色"。
若这部分对不上，说明 §2.1 的 $y$ 除错了位置（例如误用了 $Y=x/y$ 之类的错式）。

## 9. 常见错误清单

| 症状 | 原因 |
|---|---|
| 白点对不上 | §2.2 的方程组解在错误的基上；或白点向量用了未归一化的色度而非 $Y=1$ 形式 |
| 原色对不上但白点对得上 | §2.3 组装时列缩放用错了 $S$ 的分量顺序 |
| 整体系数偏一个常数倍 | 忘了 §3.1 的按 Y 归一，或重复归一化 |
| 逆变换后暗部出现负值 | 正常现象（色域外），见 §4.3 |
| 串联后结果乱了 | §6 的乘法顺序反了 |
| 行和不为 1 | 误用了 §3.1 去实现"按行归一" |
