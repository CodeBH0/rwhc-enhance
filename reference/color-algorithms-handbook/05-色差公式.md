# 05 · 色差公式

> 本篇规定"两个颜色差多少"的量化方法。三代公式（CIE76 / CIE94 / CIEDE2000）全部给出。
> 概念背景（为什么需要感知均匀空间）见 `00-从零理解色彩数学.md` §6。

---

## 1. 选择指南

| 公式 | 何时用 | 复杂度 |
|---|---|---|
| $\Delta E^*_{ab}$（CIE76）| 粗算、内部排序、不关心跨色区一致性 | 极低 |
| $\Delta E^*_{94}$ | 既有管线兼容；印刷/纺织有既定参数 | 低 |
| $\Delta E_{00}$ | **默认推荐**；需要与人眼判断一致时 | 中 |

**统一建议**：新项目用 $\Delta E_{00}$。本文档把三代都列出，是因为跨系统比对标定时常需要它们同时存在。

---

## 2. 输入约定

所有公式**均在 CIELAB 空间计算**，因此输入是 $(L^*, a^*, b^*)$。

若手上是 $(X,Y,Z)$，先按 `01-色度坐标变换.md` §5.1 转换，**并确认参考白点一致**——
两个颜色必须在**同一个**参考白点下换算，否则 $a^*,b^*$ 不可比。

---

## 3. 第一代：$\Delta E^*_{ab}$（CIE76）

$$
\Delta E^*_{ab} = \sqrt{(\Delta L^*)^2 + (\Delta a^*)^2 + (\Delta b^*)^2}
$$

其中 $\Delta L^* = L_1^* - L_2^*$，其余同理。

**性质**：就是 Lab 空间的欧氏距离。
**缺陷**：Lab 只是"大致"均匀，在彩度高/低、色相不同区域的宽容度差异没有体现。

---

## 4. 第二代：$\Delta E^*_{94}$（CIE94）

### 4.1 分解

先把差异分解到三个**感知维度**：

$$
\Delta L^* = L_1^* - L_2^*
$$

$$
C_i^* = \sqrt{a_i^{*2} + b_i^{*2}},\qquad \Delta C^* = C_1^* - C_2^*
$$

$$
\Delta H^* = \sqrt{(\Delta a^*)^2 + (\Delta b^*)^2 - (\Delta C^*)^2}
$$

> **$\Delta H^*$ 从哪来**：总差异的平方 = 明度差² + 彩度差² + 色相差²（这是勾股定理在直角坐标下的必然结果）。
> 所以移项即得。注意被开方数可能因浮点误差出现极小负数，实现时应 `max(..., 0)`。

### 4.2 加权

$$
S_L = 1,\qquad S_C = 1 + K_1 C_1^*,\qquad S_H = 1 + K_2 C_1^*
$$

$$
\Delta E^*_{94} = \sqrt{
\left(\frac{\Delta L^*}{k_L S_L}\right)^2 +
\left(\frac{\Delta C^*}{k_C S_C}\right)^2 +
\left(\frac{\Delta H^*}{k_H S_H}\right)^2
}
$$

### 4.3 参数

| 参数 | 图形艺术 | 纺织 |
|---|---|---|
| $K_1$ | **0.045** | 0.048 |
| $K_2$ | **0.015** | 0.014 |

$k_L, k_C, k_H$ 是应用权重，默认全为 1。只有在特定场景才调整（如 $k_L = 2$ 用于放宽明度要求）。

**本手册默认采用图形艺术参数**（$0.045,\ 0.015$）。

### 4.4 用哪个 $C^*$

公式里 $S_C, S_H$ 用的是**第一个颜色**的 $C_1^*$（参考色）。
这是 CIE94 的一个已知不对称性：$\Delta E(a,b) \ne \Delta E(b,a)$。

**实践建议**：始终把**参考色（目标色）**放在第 1 位。

## 5. 第三代：$\Delta E_{00}$（CIEDE2000）

### 5.1 前置修正

先用 $G$ 拉伸 $a^*$，改善低彩度区的表现：

$$
\bar C^* = \frac{C_1^* + C_2^*}{2}
$$

$$
G = \frac{1}{2}\left(1 - \sqrt{\frac{\bar C^{*7}}{\bar C^{*7} + 25^{7}}}\right)
$$

$$
a_i' = (1 + G)\,a_i^*,\qquad C_i' = \sqrt{a_i'^2 + b_i^{*2}}
$$

> $25^7$ 是**实验拟合**出来的数字，没有解析来源。照抄即可。

### 5.2 色相角

$$
h_i' = \operatorname{atan2}(b_i^*,\ a_i')\quad\text{化为角度}\ [0°,360°)
$$

$$
\Delta h' = \begin{cases}
h_2' - h_1', & |h_2' - h_1'| \le 180°\\
h_2' - h_1' - 360°, & h_2' - h_1' > 180°\\
h_2' - h_1' + 360°, & h_2' - h_1' < -180°
\end{cases}
$$

$$
\Delta H' = 2\sqrt{C_1' C_2'}\ \sin\!\left(\frac{\Delta h'}{2}\right)
$$

### 5.3 均值项（注意色相均值的环形处理）

$$
\bar L' = \frac{L_1^* + L_2^*}{2},\qquad
\bar C' = \frac{C_1' + C_2'}{2}
$$

$$
\bar h' = \begin{cases}
\dfrac{h_1' + h_2'}{2}, & |h_1' - h_2'| \le 180°\\[2mm]
\dfrac{h_1' + h_2' + 360°}{2}, & |h_1' - h_2'| > 180°,\ h_1' + h_2' < 360°\\[2mm]
\dfrac{h_1' + h_2' - 360°}{2}, & |h_1' - h_2'| > 180°,\ h_1' + h_2' \ge 360°
\end{cases}
$$

> **这是全公式最容易写错的地方**：色相均值必须在圆环上取"较近的那一边"的中间值，
> 直接算术平均会在 $0°$ 附近（红紫色区）给出完全错误的结果。

### 5.4 权重函数

$$
T = 1 - 0.17\cos(\bar h' - 30°) + 0.24\cos(2\bar h') + 0.32\cos(3\bar h' + 6°) - 0.20\cos(4\bar h' - 63°)
$$

$$
S_L = 1 + \frac{0.015\,(\bar L' - 50)^2}{\sqrt{20 + (\bar L' - 50)^2}}
$$

$$
S_C = 1 + 0.045\,\bar C'
$$

$$
S_H = 1 + 0.015\,\bar C'\,T
$$

### 5.5 色相旋转项

$$
\Delta\theta = 30\exp\!\left[-\left(\frac{\bar h' - 275°}{25}\right)^2\right]
$$

$$
R_C = 2\sqrt{\frac{\bar C'^{7}}{\bar C'^{7} + 25^{7}}}
$$

$$
R_T = -\sin(2\Delta\theta)\,R_C
$$

（$R_T$ 专门修正蓝紫区——$\bar h'$ 在 $275°$ 附近——特有的色相位移。）

### 5.6 合成

$$
\Delta E_{00} = \sqrt{
\left(\frac{\Delta L'}{k_L S_L}\right)^2 +
\left(\frac{\Delta C'}{k_C S_C}\right)^2 +
\left(\frac{\Delta H'}{k_H S_H}\right)^2 +
R_T\,\frac{\Delta C'}{k_C S_C}\,\frac{\Delta H'}{k_H S_H}
}
$$

其中 $\Delta L' = L_1^* - L_2^*$，$\Delta C' = C_1' - C_2'$。

**注意最后一项是乘积项，不是平方项**——这是 $\Delta E_{00}$ 与 CIE94 结构上唯一的差别。

## 6. 其他色差

### 6.1 $\Delta E_{uv}$（CIE 1976 Luv 色差）

$$
\Delta E_{uv} = \sqrt{(\Delta L^*)^2 + (\Delta u^*)^2 + (\Delta v^*)^2}
$$

用于**发光体**（显示器、光源）比对，与 $u'v'$ 色度图衔接自然。

### 6.2 $\Delta u'v'$（色度差，不含亮度）

$$
\Delta u'v' = \sqrt{(u_1' - u_2')^2 + (v_1' - v_2')^2}
$$

专门衡量**色度**差异，在照明领域有既定阈值（如 < 0.0054 表示色度"难以察觉"）。

### 6.3 Judd-Vos 修正（对短波段 CMF 的修正）

在部分应用（尤其涉及深蓝、紫色的高精度计算）中，需先对色度做一次修正：

$$
\text{den} = 0.03845\,x + 0.01496\,y + 1
$$

$$
x' = \frac{1.0271\,x - 0.00008\,y - 0.00009}{\text{den}}
$$

$$
y' = \frac{0.00376\,x + 1.0072\,y + 0.00764}{\text{den}}
$$

若 $\text{den} = 0$ 返回错误。

**适用条件**：修正的是 CIE 1931 2° 观察者在约 380–460 nm 区间与实验数据的偏差。
若不涉及短波段的精确比对，可跳过。

## 7. 尺度参考

$\Delta E_{00}$ 的经验刻度（显示器/印刷场景，粗参考）：

| 值 | 含义 |
|---|---|
| < 1.0 | 肉眼几乎不可分辨 |
| 1.0 – 2.0 | 训练有素者勉强可察觉 |
| 2.0 – 3.5 | 普通观察者可察觉 |
| 3.5 – 5.0 | 明显不同 |
| > 5.0 | 不同颜色 |

不同研究的阈值不完全一致，上表只用于量级判断。

## 8. 实现清单（$\Delta E_{00}$）

```python
import math

def de2000(lab1, lab2, kL=1.0, kC=1.0, kH=1.0):
    L1, a1, b1 = lab1
    L2, a2, b2 = lab2

    C1 = math.hypot(a1, b1)
    C2 = math.hypot(a2, b2)
    Cb = 0.5*(C1 + C2)
    C7 = Cb**7
    G  = 0.5*(1.0 - math.sqrt(C7/(C7 + 25.0**7)))

    a1p, a2p = (1.0+G)*a1, (1.0+G)*a2
    C1p, C2p = math.hypot(a1p, b1), math.hypot(a2p, b2)

    h1p = math.degrees(math.atan2(b1, a1p)) % 360.0
    h2p = math.degrees(math.atan2(b2, a2p)) % 360.0

    dLp = L2 - L1
    dCp = C2p - C1p

    if C1p*C2p == 0.0:
        dhp = 0.0
    else:
        d = h2p - h1p
        if   d >  180.0: dhp = d - 360.0
        elif d < -180.0: dhp = d + 360.0
        else:            dhp = d
    dHp = 2.0*math.sqrt(C1p*C2p)*math.sin(math.radians(dhp)/2.0)

    Lbp = 0.5*(L1 + L2)
    Cbp = 0.5*(C1p + C2p)

    if C1p*C2p == 0.0:
        hbp = h1p + h2p
    else:
        s = h1p + h2p
        if abs(h1p - h2p) <= 180.0: hbp = 0.5*s
        elif s < 360.0:             hbp = 0.5*(s + 360.0)
        else:                       hbp = 0.5*(s - 360.0)

    T = (1.0 - 0.17*math.cos(math.radians(hbp - 30.0))
             + 0.24*math.cos(math.radians(2.0*hbp))
             + 0.32*math.cos(math.radians(3.0*hbp + 6.0))
             - 0.20*math.cos(math.radians(4.0*hbp - 63.0)))

    SL = 1.0 + 0.015*(Lbp - 50.0)**2 / math.sqrt(20.0 + (Lbp - 50.0)**2)
    SC = 1.0 + 0.045*Cbp
    SH = 1.0 + 0.015*Cbp*T

    dth = 30.0*math.exp(-(((hbp - 275.0)/25.0)**2))
    C7b = Cbp**7
    RC  = 2.0*math.sqrt(C7b/(C7b + 25.0**7))
    RT  = -math.sin(math.radians(2.0*dth))*RC

    t1 = dLp/(kL*SL); t2 = dCp/(kC*SC); t3 = dHp/(kH*SH)
    return math.sqrt(t1*t1 + t2*t2 + t3*t3 + RT*t2*t3)
```

## 9. 自检用例

标准 $\Delta E_{00}$ 测试向量（$k_L=k_C=k_H=1$）。下面 8 组足以验证实现：

| # | Lab₁ | Lab₂ | 期望 $\Delta E_{00}$ |
|---:|---|---|---|
| 1 | 50.0000, 2.6772, −79.7751 | 50.0000, 0.0000, −82.7485 | 2.0425 |
| 2 | 50.0000, 3.1571, −77.2803 | 50.0000, 0.0000, −82.7485 | 2.8615 |
| 3 | 50.0000, 2.8361, −74.0200 | 50.0000, 0.0000, −82.7485 | 3.4412 |
| 4 | 50.0000, −1.3802, −84.2814 | 50.0000, 0.0000, −82.7485 | 1.0000 |
| 5 | 50.0000, 0.0000, 0.0000 | 50.0000, −1.0000, 2.0000 | 2.3669 |
| 6 | 50.0000, 2.5000, 0.0000 | 73.0000, 25.0000, −18.0000 | 4.3065 |
| 7 | 60.2574, −34.0099, 36.2677 | 60.4626, −34.1751, 39.4387 | 2.0000 |
| 8 | 2.0776, 0.0795, −1.1350 | 0.9033, −0.0636, −0.5514 | 3.2693 |

**两个快速健全性检查**：

- 同一个颜色与自身：$\Delta E_{00} = 0$。
- 只有明度不同：$\Delta E_{00}(50,0,0\ \text{vs}\ 60,0,0) \approx 9.47$。
  （若得到 10.0，说明漏了 $S_L$；若得到别的数，检查 $\bar L'$ 是否取了两者均值 55 而非 50。）

**对称性**：$\Delta E_{00}(A,B) = \Delta E_{00}(B,A)$ 应当成立。
若你的实现不满足，检查色相均值 $\bar h'$ 的分支处理。
