# 02 · 色温与黑体轨迹

> 本篇规定"色温 $\leftrightarrow$ 色度坐标"的双向换算。
> 概念背景（黑体辐射、相关色温的几何意义）见 `00-从零理解色彩数学.md` §4。

---

## 1. 术语与两条不同的轨迹

| 术语 | 含义 |
|---|---|
| **黑体轨迹**（Planckian locus）| 理想黑体在温度 $T$ 下的色度点连成的曲线 |
| **日光轨迹**（Daylight locus）| CIE D 系列对自然日光的经验拟合曲线 |
| **CCT** | 相关色温：色度点到黑体轨迹的**最近点**温度 |
| **CCT(D)** | 若按日光轨迹定义，则称为"相关色温（日光）" |

两条曲线**不重合**：在 6500 K 附近，日光轨迹的色度点比黑体轨迹略偏绿。
选哪条取决于应用：

- **发光体**（灯泡、白炽）：用黑体轨迹。
- **显示设备白点、标准照明体 $D_{50}/D_{65}$**：用日光轨迹。
- 冷色温（> 7000 K）下两者差异明显，不可混用。

## 2. 正向：$T \to (x,y)$

### 2.1 分段总览

规定如下分段（这是本篇的核心约定，务必完整实现每个分支）：

| 温度区间 | 处理方式 |
|---|---|
| $T < 2000$ | **无效**，返回错误 |
| $2000 \le T < 3500$ | 黑体轨迹（Planck 积分，§2.2）|
| $3500 \le T < 4000$ | **未定义**，返回错误（见 §2.5）|
| $4000 \le T \le 7000$ | 日光轨迹，分支 A（§2.3）|
| $7000 < T \le 25000$ | 日光轨迹，分支 B（§2.4）|
| $T > 25000$ | **无效**，返回错误 |

> 若你的应用需要覆盖 3500–4000 K，请**显式**选择：要么用分支 A 向低温外推，
> 要么用黑体轨迹向高温外推，要么线性混合两者。**不要默默沿用错误返回**，
> 否则调用方拿到的是未初始化值。

### 2.2 黑体轨迹（$2000 \le T < 3500$）

用 Planck 定律算出光谱，再对 CIE 1931 标准观察者的三组色匹配函数做积分。

$$
M(\lambda, T) = \frac{2\pi h c^2}{\lambda^5}\cdot
\frac{1}{\exp\!\left(\dfrac{hc}{\lambda k T}\right) - 1}
$$

其中波长先转为米并乘空气修正因子：

$$
\lambda_m = \lambda_{\text{nm}} \times 10^{-9} \times 1.00028
$$

**逐波长求和**（色匹配表见 `data/cie1931_2deg_1nm.json`，380–780 nm 步进 1 nm，共 401 项）：

$$
S_x = \sum_i M(\lambda_i, T)\,\bar{x}(\lambda_i),\quad
S_y = \sum_i M(\lambda_i, T)\,\bar{y}(\lambda_i),\quad
S_z = \sum_i M(\lambda_i, T)\,\bar{z}(\lambda_i)
$$

$$
x = \frac{S_x}{S_x+S_y+S_z},\qquad y = \frac{S_y}{S_x+S_y+S_z}
$$

**常量取值**（本手册规定）：

| 常量 | 值 |
|---|---|
| $hc$ | `1.9864458571489286e-25` |
| $2\pi h c^2$ | `3.741771852192758e-16` |
| $k$（Boltzmann）| `1.38064903e-23` |
| 空气因子 $A$ | `1.00028` |
| $A^2$ | `1.0005600784000002` |

> 注意 $2\pi hc^2$ 里带 $\pi$（而不是常见的 $2hc^2$），且分母的 $\lambda^5$ 用的是**空气修正后**的 $\lambda_m$，
> 同时还要再除一次 $A^2$。这三个细节如果漏掉，色度会偏。

### 2.3 日光轨迹分支 A（$4000 \le T \le 7000$）

$$
x_D = -4.6070\times10^{9}/T^3 + 2.9678\times10^{6}/T^2 + 0.09911\times10^{3}/T + 0.244063
$$

### 2.4 日光轨迹分支 B（$7000 < T \le 25000$）

$$
x_D = -2.0064\times10^{9}/T^3 + 1.9018\times10^{6}/T^2 + 0.24748\times10^{3}/T + 0.237040
$$

### 2.5 两条分支共用的 y

$$
y_D = -3.000\,x_D^{2} + 2.87\,x_D - 0.275
$$

## 3. 反向：$(x,y) \to$ CCT

### 3.1 拟合式

定义中间参数

$$
t = \frac{x - a}{y - b},\qquad a = 0.332,\quad b = 0.1858
$$

则

$$
\boxed{\ \text{CCT} \approx \big((k_3 - k_2 t)\,t - k_1\big)\,t + k_0\ }
$$

**系数组**（本手册采用）：

$$
k_3 = 437.0,\qquad k_2 = 3601.0,\qquad k_1 = 6861.0,\qquad k_0 = 5514.31
$$

展开即：

$$
\text{CCT} = -437\,t^3 + 3601\,t^2 - 6861\,t + 5514.31
$$

若 $y = 0.1858$（即 $t$ 的分母为 0）：返回错误，不写输出。

### 3.2 关于系数的说明

这个三次式是 **McCamy 近似** 结构。文献中常见的另一组系数是 $449/3525/6823.3/5520.33$，
并且 $t$ 的符号约定可能相反。**不同来源的系数不可混用**——它们是在不同的色度数据上拟合出来的。

本手册采用 $437/3601/6861/5514.31$，与其配套的 $t$ 定义见 §3.1。

### 3.3 适用范围（务必注意）

该拟合式**不含任何有效性检查**，对任意 $y \ne 0.1858$ 的输入都会算出数值。但：

- 只在**靠近黑体/日光轨迹**时有物理意义；
- 对纯绿、纯蓝等远离轨迹的色度，会给出**毫无意义的巨大数值**；
- 建议调用前先用 $u'v'$ 距离做一次"是否在轨迹附近"的判断（见 §4）。

---

## 4. 有效性判据（推荐做法）

为了判断一个色度点是否适合用色温描述，计算它到轨迹的**最短距离**（在 $u'v'$ 空间量）：

$$
d = \min_{T \in [T_{\min}, T_{\max}]}
\sqrt{\big(u'(x,y) - u'(x_D(T), y_D(T))\big)^2 + \big(v'(x,y) - v'(T)\big)^2}
$$

经验阈值：$d \lesssim 0.05$ 时可认为在轨迹附近，色温描述有意义。
更严格的标准（如 $\Delta u'v' < 0.0054$）用于照明品质评估。

## 5. 实现清单

```python
import json, math, os

HC      = 1.9864458571489286e-25
TWOPIHC2 = 3.741771852192758e-16
KB      = 1.38064903e-23
AIR     = 1.00028
AIR2    = 1.0005600784000002

A3, A2, A1, A0 = -4.607,  2.9678, 0.09911, 0.244063   # 4000..7000
B3, B2, B1, B0 = -2.0064, 1.9018, 0.24748, 0.237040   # 7000..25000

K3, K2, K1, K0 = 437.0, 3601.0, 6861.0, 5514.31
CA, CB = 0.332, 0.1858

def planck(lam_nm, T):
    lam = lam_nm * 1e-9 * AIR
    return TWOPIHC2 / (lam**5 * AIR2) / (math.exp(HC / (lam * KB * T)) - 1.0)

_CMF = None
def cmf(path=None):
    global _CMF
    if _CMF is None:
        p = path or os.path.join(os.path.dirname(__file__), "data",
                                 "cie1931_2deg_1nm.json")
        _CMF = json.load(open(p, encoding="utf-8"))["rows"]
    return _CMF

def cct_to_xy_blackbody(T, cmf_rows):
    sx = sy = sz = 0.0
    for lam, xb, yb, zb in cmf_rows:
        M = planck(lam, T)
        sx += M*xb; sy += M*yb; sz += M*zb
    s = sx + sy + sz
    return (sx/s, sy/s)

def daylight_x(T):
    if 4000.0 <= T <= 7000.0:
        return A3*1e9/T**3 + A2*1e6/T**2 + A1*1e3/T + A0
    if 7000.0 < T <= 25000.0:
        return B3*1e9/T**3 + B2*1e6/T**2 + B1*1e3/T + B0
    raise ValueError("out of range")

def cct_to_xy(T, cmf_rows=None):
    if T < 2000.0 or T > 25000.0:      return None
    if 3500.0 <= T < 4000.0:           return None   # 未定义区间
    if T < 3500.0:
        return cct_to_xy_blackbody(T, cmf_rows or cmf())
    x = daylight_x(T)
    return (x, -3.0*x*x + 2.87*x - 0.275)

def xy_to_cct(x, y):
    den = y - CB
    if den == 0.0: return None
    t = (x - CA) / den
    return ((K3 - K2*t)*t - K1)*t + K0
```
