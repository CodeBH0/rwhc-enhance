# 01 · 色度坐标变换

> 本篇规定各坐标系统之间的标准换算。所有公式可直接实现，无需外部依赖。
> 背景概念（三刺激值、色度坐标的几何意义）见 `00-从零理解色彩数学.md`。

---

## 1. 符号与约定

| 符号 | 含义 | 典型范围 |
|---|---|---|
| $X, Y, Z$ | 三刺激值 | $Y \in [0,1]$（相对）或 cd/m²（绝对）|
| $x, y$ | 色度坐标 | $[0,1]$，且 $x+y \le 1$ |
| $X_n, Y_n, Z_n$ | **参考白点**的三刺激值 | 通常 $Y_n = 1$ |
| $L^*$ | 明度 | $[0, 100]$ |
| $a^*, b^*$ | 红–绿轴、黄–蓝轴 | 约 $[-128, 127]$（可超出）|
| $C^*, h$ | 彩度、色相角 | $C^* \ge 0$，$h$ 见 §5.3 |
| $u', v'$ | CIE 1976 均匀色度坐标 | — |

**错误处理约定**（全篇统一）：

- 分母为 0 或参考白点分量为 0 时，函数应**返回错误指示，并且不修改输出变量**。
  调用方需自行保证输出已初始化为安全值。
- 不要"返回 0 填充"——那会让调用方无法区分"成功且结果为 0"与"失败"。

---

## 2. 三刺激值 ↔ 色度坐标

### 2.1 $(X,Y,Z) \to (x,y)$

$$
s = X + Y + Z;\qquad
x = \frac{X}{s},\quad y = \frac{Y}{s}
$$

若 $s = 0$：返回错误（黑体无颜色，不写输出）。

### 2.2 $(Y,x,y) \to (X,Z)$

由 $x = X/s$、$y = Y/s$ 反解（$s = X+Y+Z$）：

$$
X = \frac{Y\,x}{y},\qquad Z = \frac{Y\,(1 - x - y)}{y}
$$

若 $y = 0$：返回错误。

> **实现注意**：$Z$ 的表达式请**原样**写成 $Y(1-x-y)/y$，不要改写为 $Y(1-x)/y - Y$。
> 两者数学等价，但浮点求值路径不同，末位会有差异。做逐位对齐时这是真实存在的坑。

### 2.3 完整互转 $(X,Y,Z) \leftrightarrow (Y,x,y)$

两者信息量相同（3 个自由度）。$\to$ 方向用 §2.1 加 $Y$ 本身；$\leftarrow$ 方向用 §2.2 加 $Y$ 本身。

## 3. CIE 1976 均匀色度坐标 $u'v'$

### 3.1 从 XYZ

$$
D = X + 15Y + 3Z,\qquad u' = \frac{4X}{D},\quad v' = \frac{9Y}{D}
$$

### 3.2 从 $xy$

$$
D = -2x + 12y + 3,\qquad u' = \frac{4x}{D},\quad v' = \frac{9y}{D}
$$

（两式等价：把 §2.1 代入 §3.1 即得。注意这里 $D$ 的正负号与上一节不同，是化简后的结果。）

### 3.3 逆变换 $(u',v') \to (x,y)$

$$
D = 6u' - 16v' + 12,\qquad x = \frac{9u'}{D},\quad y = \frac{4v'}{D}
$$

### 3.4 与 CIE 1960 $uv$ 的关系

CIE 1976 的定义是 $u' = u$、$v' = 1.5\,v$（$u,v$ 为 1960 定义）。
若手上数据是 1960 版，先做这个缩放再套用本篇公式。

> **为什么要换成 $u'v'$**：$xy$ 图上相同"距离"在不同区域对应的视觉差异可以相差数倍；
> $u'v'$ 图上的距离与视觉差异的相关性好得多。凡是要算"看起来差多少"（相关色温、色差、色域距离），
> 都应换到 $u'v'$ 或 Lab/Luv 空间进行。

## 4. f 函数：Lab / Luv 共用的非线性核心

$$
f(t) = \begin{cases}
t^{1/3}, & t > \varepsilon\\[2mm]
\dfrac{t - c}{s}, & \text{否则}
\end{cases}
$$

**由"接点处值与一阶导连续"解出的常数**：

$$
\varepsilon = \left(\frac{6}{29}\right)^{3} = 0.008856451679\ldots,\qquad
s = \frac{1}{3}\varepsilon^{-2/3} = 7.787037\ldots,\qquad
c = \frac{4}{29} = 0.13793103448275862
$$

**数值近似约定**：工程实现中允许使用

$$
\varepsilon \approx 0.008856,\qquad s \approx 7.787
$$

但 $c$ 应保留精确值 $4/29$。这样做的理由是历史兼容性——
若你的项目需要与既有实现**逐位一致**，请沿用上面这组近似值；若只要求视觉一致，用精确值更好。

## 5. CIELAB

### 5.1 正向 $(X,Y,Z) \to (L^*,a^*,b^*)$

$$
\begin{aligned}
f_x &= f(X/X_n),\quad f_y = f(Y/Y_n),\quad f_z = f(Z/Z_n)\\[1mm]
L^* &= 116\,f_y - 16\\
a^* &= 500\,(f_x - f_y)\\
b^* &= 200\,(f_y - f_z)
\end{aligned}
$$

若 $X_n,Y_n,Z_n$ 任一为 0：返回错误。

### 5.2 逆变换 $(L^*,a^*,b^*) \to (X,Y,Z)$

$$
f_y = \frac{L^* + 16}{116},\qquad
f_x = f_y + \frac{a^*}{500},\qquad
f_z = f_y - \frac{b^*}{200}
$$

$$
f^{-1}(v) = \begin{cases}
v^3, & v^3 > \varepsilon\\[1mm]
\dfrac{v - c}{s}, & \text{否则}
\end{cases}
\qquad
X = X_n f^{-1}(f_x),\quad Y = Y_n f^{-1}(f_y),\quad Z = Z_n f^{-1}(f_z)
$$

### 5.3 派生量

$$
C^* = \sqrt{a^{*2} + b^{*2}}
$$

$$
h = \operatorname{atan2}(b^*, a^*)\quad\text{（标准约定，值域 } (-\pi, \pi]\text{）}
$$

> ⚠️ **色相角有两套约定，务必先确认**：
>
> | 约定 | 表达式 | 值域 | 第二/四象限 |
> |---|---|---|---|
> | A（CIE 标准）| $\operatorname{atan2}(b^*,a^*)$ | $(-\pi,\pi]$ | 得 $\pm$ 接近 $\pi$ 的值 |
> | B（工程变体）| $\arctan(b^*/a^*)$ | $(-\pi/2,\pi/2]$ | 得接近 $0$ 的值 |
>
> 两者在第一、三象限完全相同，在第二、四象限差 $\pi$。
> 约定 B 的等价稳健写法（避免 $a=0$ 除零）：
>
> ```python
> h = math.atan2(b, a)
> if h >  math.pi/2: h -= math.pi
> elif h < -math.pi/2: h += math.pi
> ```
>
> 注意边界用**严格**不等号：$a=0, b<0$ 时 $\operatorname{atan2}=-\pi/2$ 应原样保留。

## 6. CIELUV

### 6.1 正向

$$
L^* = \begin{cases}
116\,(Y/Y_n)^{1/3} - 16, & Y/Y_n > \varepsilon\\[1mm]
\kappa\,(Y/Y_n), & \text{否则}
\end{cases}
\qquad \kappa = 903.292
$$

$$
\begin{aligned}
D  &= X  + 15Y  + 3Z\\
D_n&= X_n+ 15Y_n+ 3Z_n\\
u^* &= 13\,L^*\left(\frac{4X}{D} - \frac{4X_n}{D_n}\right)
     = 13\,L^*\,(u' - u'_n)\\
v^* &= 13\,L^*\left(\frac{9Y}{D} - \frac{9Y_n}{D_n}\right)
     = 13\,L^*\,(v' - v'_n)
\end{aligned}
$$

> **注意 $\kappa$ 的取值**：本手册规定 Luv 使用 $\kappa = 903.292$。
> 它与 §4 由连续性条件解出的 $903.296296\ldots$ 略有不同，是历史近似留下的差异。
> 若同一份代码里既做 Luv 又做"L\*→Y"的查表，不要混用这两个值。

### 6.2 逆变换（概要）

由 $L^*$ 反解 $Y$（用 $\kappa$ 或 $\varepsilon$ 分支），再由 $u^*,v^*$ 反解 $u',v'$，
最后经 §3.3 得到 $x,y$、经 §2.2 得到 $X,Z$。

## 7. 实现清单

```python
import math

EPS   = 0.008856                  # (6/29)^3 的近似
SLOPE = 7.787                     # 1/(3*eps^(2/3)) 的近似
ICPT  = 0.13793103448275862       # 精确 4/29
KAPPA = 903.292                   # Luv 专用

def f_fwd(t):
    return t ** (1.0/3.0) if t > EPS else t * SLOPE + ICPT

def f_inv(v):
    v3 = v*v*v
    return v3 if v3 > EPS else (v - ICPT) / SLOPE

def xyz_to_xy(X, Y, Z):
    s = X + Y + Z
    if s == 0.0: return None
    return (X/s, Y/s)

def yxy_to_XZ(Y, x, y):
    if y == 0.0: return None
    return (Y*x/y, Y*(1.0 - x - y)/y)

def xyz_to_lab(X, Y, Z, Xn, Yn, Zn):
    if Xn == 0.0 or Yn == 0.0 or Zn == 0.0: return None
    fx, fy, fz = f_fwd(X/Xn), f_fwd(Y/Yn), f_fwd(Z/Zn)
    L = 116.0*fy - 16.0
    a = 500.0*(fx - fy)
    b = 200.0*(fy - fz)
    return (L, a, b, math.hypot(a, b), hue(a, b))

def lab_to_xyz(L, a, b, Xn, Yn, Zn):
    fy = (L + 16.0)/116.0
    fx = fy + a/500.0
    fz = fy - b/200.0
    return (f_inv(fx)*Xn, f_inv(fy)*Yn, f_inv(fz)*Zn)

def hue(a, b):
    """约定 B：值域 (-pi/2, pi/2]。若需约定 A 请改用 atan2。"""
    if a == 0.0 and b == 0.0: return 0.0
    h = math.atan2(b, a)
    if   h >  math.pi/2: h -= math.pi
    elif h < -math.pi/2: h += math.pi
    return h

def xyz_to_uv1976(X, Y, Z):
    d = X + 15.0*Y + 3.0*Z
    if d == 0.0: return None
    return (4.0*X/d, 9.0*Y/d)

def xy_to_uv1976(x, y):
    d = -2.0*x + 12.0*y + 3.0
    if d == 0.0: return None
    return (4.0*x/d, 9.0*y/d)

def uv1976_to_xy(u, v):
    d = 6.0*u - 16.0*v + 12.0
    if d == 0.0: return None
    return (9.0*u/d, 4.0*v/d)
```
